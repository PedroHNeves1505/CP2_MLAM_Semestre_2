## Objetivo

###Parte 1
* Obter dados do PVGIS sobre potência fotovoltaica, irradiação solar, temperatura, velocidade do vento e posição/altura solar e com eles fazer um modelo de teste de machine learning.

###Parte 2
* Investigar a existência de uma relação entre a atividade econômica brasileira e o fluxo rodoviário de veículos. Para isso, o trabalho propõe a pesquisa de dados oficiais de longo prazo — utilizando o índice de volume do PIB do IBGE e o Índice ABCR de fluxo de veículos ao longo de 20 anos —, a estruturação de uma base de dados anual e o desenvolvimento de um modelo de regressão linear em Python. Por fim, a atividade visa treinar e avaliar o modelo preditivo utilizando métricas estatísticas e interpretar criticamente os resultados obtidos, compreendendo a dinâmica entre o tráfego logístico e a macroeconomia sem assumir uma relação simplista de causa e efeito.
